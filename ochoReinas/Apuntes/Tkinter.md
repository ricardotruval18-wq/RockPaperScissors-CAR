# Tkinter

*Tkinter es la libreria estandar de Pythom para interfaz grafica de usuario o GUI(Graphic User Interface), funciona como un wrapper de python encima de Tcl/Tk la cual es una herramienta para construir interfaces*

- Wrapper:
  Un wrapper es un fragmento de codigo que envuelve a otro componente, es exactamente como una funcion, se usa para adaptar, simplificar o cambiar su uso sin afectar a una estructura principal. Son como lo dice su nombre, contenedores, no solo de codigo(como una funcion) si no que tambien pueden contener componentes, sistemas, funciones etc.
*En este caso Tkinter es un wrapper que almacena a un sistema de GUI, el Tcl/Tk el cual es un programa escrito en C y Tcl. Tkinter es el puente que conecta el codigo complejo en C con python*
